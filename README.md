### 📊 [ESPT Competizione — web de estadísticas](https://github.com/danielgonhid/espt-web)
 
Web de estadísticas históricas de la liga privada de Assetto Corsa en la que corro: clasificación histórica, ficha de cada piloto y comparador cara a cara.
 
- Sin backend: todo sale de un único `data.json`. Actualizar la liga es editar el JSON y hacer push.
- Módulos ES cargados bajo demanda: si una sección falla, el resto de la página sigue funcionando.
- Todo dato del JSON se escapa antes de insertarse en el HTML (prevención de XSS).
- Flujo de ramas `main` (producción) / `dev` (pruebas).
